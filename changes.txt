# J~Net Thermal Printer - Changes Log

## 2026-08-19 - v1.0.1
### Changes
- Added "Save as Template" button in Print Template (Receipt) mode
  - Saves the current receipt layout as a reusable, named template (prompts for a name)
  - Shop/receipt fields are baked into the template layout; the item list stays as the
    {items} placeholder so new versions can simply refill the items and reprint
  - The saved template appears in the template picker and can be edited afterwards
    (lines, style, alignment, size, logo) via the Template Editor
  - After saving you can jump straight into the editor
- {items} placeholder now works in any text line
  - "instead of added items it just says {items}" is fixed: when the item list is
    present it is expanded into the receipt at that point; when empty it prints nothing
- Added "Add Logo" button in Print Template (Receipt) mode (with "Remove Logo")
  - Choose an image from storage; it is stored with the template
  - The logo shows as a preview at the top of the screen (top-centre) in the receipt builder
  - It is printed top-centre on the receipt when printed out (existing behaviour, now
    dependable because the logo is stored per-template and shown/confirmed in the UI)
- Version bumped to v1.0.1 (versionCode 2); update installs over v1.0.0 without uninstall
  (same ciphervault keystore)
- v1.0.0 APK backed up to Backup/J~Net-Thermal-Printer-v1.0.0.apk before this update

## 2026-08-18 - v1.0.0
### Initial Release
- Full English Android app: Bluetooth thermal POS printer (PT210 compatible)
- Connect from Android mobile via Bluetooth straight to the mobile printer
- POS receipt making via templates (style, layout, text size, logo/image)
- Template editing (add/edit/delete/reorder lines, alignment, bold, underline, dashes, spacers)
- Receipt saving (internal + export to /storage/emulated/0/Download/) and sending via email
- Printing to the thermal printer via Bluetooth (default: PT210 Thermal Printer)
- Print modes: Copy & Paste Text, Print File, Print Template (default), Print Image
- Label templates for different label sizes (58x40 default, width/height configurable in settings)
- QR code generator (generate from text, save to PNG in Downloads, print)
- QR code reader using camera (ML Kit) to reveal text to save/print
- Settings: print density/darkness, text size, layout, alignment, portrait/landscape,
  copies, paper feed, paper cut, character encoding, QR mode/module size, label sizes
- Select printer (default PT210), refresh list of paired devices
- Printer Test option in settings (prints character test pattern + QR)
- About section: Made by jnetai.com, full version number, Check for Update,
  Share App, Open GitHub Releases (falls back to releases page if check fails)
- Persistent error handling: every failure logs a clear error code, stack trace,
  device info and metadata to an in-app Diagnostics log (view in Settings)
- Dark centered themed UI with bottom padding so elements are never cut off
- Uses the shared ciphervault keystore so updates install without uninstalling
- Built via GitHub Actions workflow (tag push v* triggers signed release)
- APK published to GitHub Releases as J~Net-Thermal-Printer.apk
